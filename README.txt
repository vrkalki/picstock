PICSTOCK V1
============
Files:
- index.html : main website
- style.css  : design + responsive mobile layout
- script.js  : search, categories and demo gallery

HOW TO TEST:
1. Keep all 3 files in the same folder.
2. Open index.html in Chrome.
3. Search and category buttons will work.

HOW TO ADD REAL PNGs:
The current cards use emoji as placeholders. In the next version, we can connect each card to your real transparent PNG files and make the Download button download the actual image.
